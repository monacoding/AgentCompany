# Executive Summary

본 보고서는 Inert Gas Generator, 이하 IGG, 운전 과정에서 **화물 탱크 내부로 염분이 유입될 수 있는지**를 검토한 기술 보고서입니다.

핵심 결론은 다음과 같습니다.

```text
IGG 사용 자체만으로 화물 탱크 내 염분 유입을 단정할 수는 없다.
그러나 해수 스크러버 방식 IGG에서는 해수 자체가 염분원이므로,
데미스터·드레인·스크러버 운전 상태가 불량할 경우
염분 미스트 또는 염분 포함 응축수가 화물 탱크로 유입될 가능성은 실질적으로 존재한다.

정상 운전 조건에서는 스크러버, 데미스터, 드레인, deck water seal 또는 비반환 장치가
정상 작동한다는 전제하에 염분 유입 가능성을 낮음으로 평가한다.
반면 데미스터 손상, 스크러버 flooding, 과유속 운전, 드레인 막힘,
배관 응축수 체류가 확인될 경우 리스크는 Medium~Critical 수준으로 상향 평가해야 한다.
```

조건별 판단은 다음과 같습니다.

| 조건 | 염분 유입 가능성 | 리스크 등급 | 핵심 판단 |
|---|---:|---:|---|
| 질소 발생기 방식 등 해수 세정 공정이 없는 경우 | 매우 낮음 | Very Low~Low | 구조적으로 염분원이 제한됨 |
| 해수 스크러버 방식 + 정상 운전 | 낮음 | Low | 염분원은 있으나 방어 장치가 정상 작동 |
| 데미스터 오염·성능 저하 | 중간 | Medium | 미세 액적 후단 이동 가능 |
| 데미스터 손상·탈락 | 높음 | High~Critical | 스크러버 액적 carry-over 가능성 큼 |
| 스크러버 flooding·과유속 | 높음 | High~Critical | 액적 동반량 증가 |
| 드레인 막힘·배관 응축수 체류 | 중간~높음 | Medium~Critical | 염분수 체류·재비산·후단 이동 가능 |
| 다중 고장 상태 | 매우 높음 | Critical | 방어층 상실로 탱크 유입 가능성 매우 큼 |

최종 권고는 다음과 같습니다.

1. 탱크 투입 전 IGG 안정 운전 상태를 확인한다.  
2. 데미스터 상태를 우선 점검한다.  
3. 스크러버 flooding 및 과유속 운전을 방지한다.  
4. IG line, deck main, drain 배출 상태를 확인한다.  
5. 염분 민감 화물 적재 전에는 응축수 또는 drain water의 염분 확인을 권장한다.  
6. 비정상 운전 이력이 있으면 화물 탱크 투입 전 IG 품질 확인 절차를 강화한다.

# 4. 핵심 전제

- 해수 스크러버를 사용하는 IGG에서는 해수 자체가 염분원이다.
- 염분은 주로 해수 액적, 염분 미스트, 염분 포함 응축수 형태로 후단으로 이동할 수 있다.
- 정상 설계·정상 운전 상태에서는 데미스터와 드레인 계통이 액적 유입을 억제한다.
- 비정상 상태에서는 염분 미스트 carry-over 가능성이 상승한다.
- IGG 사용 자체가 곧 화물 탱크 염분 유입을 의미하지는 않는다.
- 염분원 존재 여부와 실제 화물 탱크 유입 가능성은 구분해서 판단해야 한다.

# 6. 염분 유입 메커니즘 정리

IGG에 의한 화물 탱크 내 염분 유입은 다음의 흐름으로 해석할 수 있습니다.

## 6.1 기본 경로

```text
IGG 연소가스 발생
→ 해수 스크러버에서 냉각·세정
→ 해수 액적 또는 미스트 발생 가능
→ 데미스터에서 액적 제거
→ 블로워 및 후단 배관
→ deck water seal / non-return device
→ deck main
→ 화물 탱크
```

## 6.2 염분 유입의 핵심 조건

염분 유입 가능성은 단순히 IGG 사용 여부만으로 결정되지 않고, 다음 조건의 조합으로 결정됩니다.

| 구분 | 핵심 조건 | 염분 유입과의 관계 |
|---|---|---|
| 염분원 존재 | 해수 스크러버 사용 | 해수 자체가 염분원이므로 가능성 존재 |
| 액적 발생 | 스크러버 내부 분무, 난류, flooding | 액적이 커질수록 carry-over 위험 증가 |
| 제거 성능 | 데미스터 정상 여부 | 성능 저하 시 후단 유입 가능성 증가 |
| 배출 성능 | 드레인 정상 여부 | 막힘·체류 시 재비산 또는 역류 가능 |
| 운전 조건 | 과유속, 압력 변동, 급격한 부하 변동 | 액적 포집 효율 저하 가능 |
| 배관 조건 | 응축수 체류, 배관 기울기 불량 | 염분 포함 수분이 탱크 방향으로 이동 가능 |
| 보호장치 상태 | deck water seal, non-return 장치 | 역류·수분 이동 차단 기능 저하 시 리스크 증가 |

# 7. 조건별 염분 미스트 유입 가능성 평가

## 7.1 평가 등급 정의

| 가능성 등급 | 의미 |
|---|---|
| 매우 낮음 | 구조적으로 염분원이 없거나, 정상 관리 상태에서 유입 경로가 거의 없음 |
| 낮음 | 이론적 가능성은 있으나 정상 장치 작동 시 유입 가능성 제한적 |
| 중간 | 특정 운전 조건 또는 일부 장치 성능 저하 시 유입 가능성 존재 |
| 높음 | 장치 이상 또는 운전 불량 시 염분 미스트 유입 가능성이 실질적으로 큼 |
| 매우 높음 | 다중 고장 또는 명백한 carry-over 상태로 탱크 유입 가능성이 매우 큼 |

## 7.2 조건별 평가표

# 8. 리스크 등급 기준

```text
리스크 = 발생 가능성 × 영향도
```

## 8.1 발생 가능성 점수

| 점수 | 등급 | 설명 |
|---:|---|---|
| 1 | 매우 낮음 | 구조적으로 가능성이 매우 제한적 |
| 2 | 낮음 | 정상 운전 시 가능성 낮음 |
| 3 | 중간 | 일부 조건 악화 시 가능성 있음 |
| 4 | 높음 | 장치 이상 시 가능성 큼 |
| 5 | 매우 높음 | 다중 고장 또는 명백한 carry-over 상태 |

## 8.2 영향도 점수

| 점수 | 등급 | 설명 |
|---:|---|---|

| 4 | 높음 | 부식·화물 오염·운항 지연 가능 |
| 5 | 매우 높음 | 화물 손상, 광범위 세정, 탱크 내부 손상 가능 |

## 8.3 리스크 등급 산정표

# 10. 영향도 평가

## 10.1 화물 품질 영향

염분 미스트가 화물 탱크에 유입될 경우, 화물 종류에 따라 영향 정도가 달라집니다.

| 화물 민감도 | 영향 |
|---|---|
| 염분 민감 화물 | 품질 저하, 수분·염분 오염 이슈 가능 |
| 일반 석유계 화물 | 직접 품질 영향은 제한적일 수 있으나 수분·염분 잔류는 관리 필요 |
| 화학제품 | 제품별 사양에 따라 오염 리스크가 커질 수 있음 |
| 청정도 요구 화물 | 탱크 세정 및 검사 부담 증가 가능 |

## 10.2 탱크 부식 영향

염분은 금속 부식의 주요 촉진 요인이 될 수 있습니다. 특히 다음 조건에서 부식 리스크가 커집니다.

- 탱크 내부에 수분이 함께 존재
- 염분이 국부적으로 농축
- 코팅 손상 부위 존재
- 고온·고습 조건
- 장기간 잔류

## 10.3 운항 및 정비 영향

염분 유입은 단순 품질 이슈뿐 아니라 운항 관리 측면에서도 영향을 줄 수 있습니다.

| 영향 항목 | 설명 |
|---|---|
| 탱크 세정 부담 | 추가 세정, 담수 rinse, 건조 필요 가능 |
| 검사 부담 | wall wash test, chloride test 등 추가 확인 가능 |
| 운항 지연 | 원인 점검 및 탱크 재검사로 일정 지연 가능 |
| 장비 정비 | 데미스터, 스크러버, 드레인, water seal 정비 필요 |

# 11. 예방·점검·운전 관리 대책

## 11.1 운전 전 확인 사항

| 점검 항목 | 확인 내용 | 목적 |
|---|---|---|
| 데미스터 상태 | 오염, 막힘, 손상, 탈락 여부 | 액적 carry-over 방지 |
| 스크러버 수위 | 정상 수위, flooding 징후 | 과도한 액적 발생 방지 |
| 스크러버 차압 | 비정상 상승 여부 | 막힘·과부하 판단 |
| 드레인 배출 | 배출 원활성, 막힘 여부 | 염분수 체류 방지 |
| deck water seal | 수위, 알람, 역류 방지 기능 | 후단 보호 |
| IG line drain | 배관 내 응축수 배출 여부 | 탱크 유입 방지 |
| 산소 농도 | 기준치 만족 여부 | IG 품질 확인 |
| 이슬점 또는 수분 상태 | 과도한 수분 동반 여부 | 응축수 및 미스트 리스크 판단 |

## 11.2 운전 중 관리 사항

- IGG 부하 급변을 피한다.
- 스크러버 유량 및 수위를 정상 범위로 유지한다.
- 블로워 운전 조건이 설계 범위를 넘지 않도록 관리한다.
- 차압 상승, 수위 변동, drain 배출 불량 알람을 즉시 확인한다.
- 탱크 투입 전 초기 불안정 가스는 충분히 배출 또는 안정화 후 사용한다.

## 11.3 운전 후 관리 사항

- IG line 및 deck main drain을 확인한다.
- 응축수 또는 염분수 체류 여부를 확인한다.
- 장기 미운전 예정 시 잔류수 제거 및 부식 방지 조치를 수행한다.
- 이상 운전 이력이 있으면 다음 운전 전 데미스터 및 스크러버 내부 점검을 우선한다.

# 12. 문장 구조·논리 흐름 검토 결과

## 12.1 논리 흐름 검토

보고서의 핵심 논리는 다음 흐름으로 정리됩니다.

```text
IGG 구성 확인
→ 해수 스크러버 사용 여부 확인
→ 해수 액적·염분 미스트 발생 가능성 확인
→ 데미스터·드레인·워터실 등 방어 장치 정상 여부 확인
→ 정상/비정상 조건별 유입 가능성 평가
→ 리스크 등급화
→ 예방·점검 대책 제시
→ 최종 결론 도출
```

이 논리 흐름은 기술 검토 보고서로 타당합니다.

특히 중요한 점은 **“염분원 존재”와 “화물 탱크 유입 가능성”을 구분한 것**입니다.

잘못된 단정 구조는 다음과 같습니다.

```text
해수 스크러버 사용
→ 해수가 염분원
→ 따라서 무조건 화물 탱크에 염분 유입
```

본 보고서는 위와 같이 단정하지 않고, 다음 구조로 판단합니다.

```text
해수 스크러버 사용
→ 해수가 염분원
→ 액적·미스트 발생 가능
→ 데미스터·드레인 등 제거 장치 존재
→ 정상 운전 시 유입 가능성 낮음
→ 방어 장치 이상 시 유입 가능성 상승
```

## 12.2 결론 명확성 검토

최종 결론은 다음 세 가지를 명확히 유지해야 합니다.

1. **“IGG 사용 자체 = 염분 유입”으로 단정하지 않는다.**  
2. **해수 스크러버 방식에서는 염분원이 존재하므로 조건부 유입 가능성이 있다.**  
3. **정상 운전에서는 낮음, 비정상 운전에서는 Medium~Critical까지 상승 가능하다는 결론을 분명히 한다.**

최종 결론 문장은 다음 형태가 가장 명확합니다.

```text
IGG 사용 자체만으로 화물 탱크 내 염분 유입을 단정할 수는 없다.
그러나 해수 스크러버 방식 IGG에서 데미스터·드레인·스크러버 운전 상태가 불량하면
염분 미스트 또는 염분 포함 응축수가 화물 탱크로 유입될 가능성은 실질적으로 존재한다.
정상 운전 조건에서는 유입 가능성을 낮음으로 평가하되,
데미스터 손상, 스크러버 flooding, 과유속, 드레인 막힘, 배관 응축수 체류가 확인될 경우
리스크는 Medium~Critical 수준으로 상향 평가해야 한다.
```

# 14. 최종 결론

IGG에 의한 화물 탱크 내 염분 유입 가능성은 **IGG 구성과 운전 상태에 따라 달라집니다.**

- **해수 스크러버를 사용하는 IGG**에서는 해수가 직접적인 염분원이므로, 염분 미스트 유입 가능성은 구조적으로 존재합니다.
- 다만 **정상 운전 조건**에서는 스크러버 후단의 데미스터, 드레인, deck water seal 또는 비반환 장치가 정상 작동한다는 전제하에 화물 탱크로의 염분 유입 가능성은 **낮음**으로 평가됩니다.
- 반대로 다음 조건이 발생하면 염분 미스트 또는 염분 포함 응축수가 후단으로 이동할 가능성이 커집니다.

  - 데미스터 오염·손상
  - 스크러버 flooding
  - 과유속 운전
  - 드레인 막힘
  - 배관 응축수 체류
  - deck water seal 수위 이상 또는 비반환 기능 불량
  - 장기 미운전 후 재가동 시 내부 잔류수·드레인 불량

- 이 경우 리스크는 **Medium에서 Critical 수준**까지 상승할 수 있습니다.

따라서 본 사안의 실무적 결론은 다음과 같습니다.

```text
IGG 사용 자체만으로 화물 탱크 내 염분 유입을 단정할 수는 없다.
그러나 해수 스크러버 방식 IGG에서는 해수 자체가 염분원이므로,
데미스터·드레인·스크러버 운전 상태가 불량할 경우
염분 미스트 또는 염분 포함 응축수가 화물 탱크로 유입될 가능성은 실질적으로 존재한다.

정상 운전 조건에서는 스크러버, 데미스터, 드레인, deck water seal 또는 비반환 장치가
정상 작동한다는 전제하에 염분 유입 가능성을 낮음으로 평가한다.
반면 데미스터 손상, 스크러버 flooding, 과유속 운전, 드레인 막힘,
배관 응축수 체류가 확인될 경우 리스크는 Medium~Critical 수준으로 상향 평가해야 한다.
```

## 14.1 최종 권고

1. 탱크 투입 전 IGG 안정 운전 상태를 확인한다.  
2. 데미스터 상태를 우선 점검한다.  
3. 스크러버 flooding 및 과유속 운전을 방지한다.  
4. IG line, deck main, drain 배출 상태를 확인한다.  
5. deck water seal 수위 및 비반환 장치 상태를 확인한다.  
6. 산소 농도뿐 아니라 이슬점 또는 과도한 수분 동반 여부를 함께 확인한다.  
7. 염분 민감 화물 적재 전에는 응축수 또는 drain water의 염분 확인을 권장한다.  
8. 비정상 운전 이력이 있으면 화물 탱크 투입 전 IG 품질 확인 절차를 강화한다.  
9. 데미스터 손상, 스크러버 flooding, 드레인 완전 막힘이 확인될 경우에는 운전 제한 또는 정지 후 원인 제거를 검토한다.
