# 선박 적용 에어 컴프레서 타입별 조사 보고서

## 1. Executive Summary

선박에서 사용되는 에어 컴프레서는 주기관 시동, 보조기관 시동, 제어 공기, 계장 공기, 서비스 공기, 비상 운전 등 선박 운항과 안전에 필요한 압축공기를 공급하는 핵심 보조기계이다.

본 보고서의 조사 대상은 **선박 압축공기 시스템용 Air Compressor**이다.  
화물 가스 압축기, 냉동 압축기, HVAC 압축기, 터보차저, 유압 펌프는 조사 범위에서 제외한다.

핵심 결론은 다음과 같다.

| 용도 | 1차 후보 | 2차 후보 | 실무 판단 |
|---|---|---|---|
| 주기관 시동 공기 | 왕복동식 | 특수 고압 스크류식 | 고압 대응성, 검증된 선박 적용 경험, 선급 승인성이 중요 |
| 보조기관 시동 공기 | 왕복동식 | 왕복동식 패키지 | Air Receiver 용량, 충전 시간, 예비기 구성 검토 필요 |
| 제어 공기 | 스크류식 | 왕복동식 | 연속 운전성, 토출 안정성, 드라이어 구성이 중요 |
| 계장 공기 | 오일프리 스크류식 + 드라이어 | 오일 윤활식 + 고성능 필터 | 수분·오일·입자 제거 품질이 핵심 |
| 서비스 공기 | 스크류식 | 왕복동식 | 유지보수성, 저진동, 에너지 효율 측면에서 스크류식 유리 |
| 비상용 공기 | 독립 구동 왕복동식 | 사양별 검토 | 전원 독립성, 정기 시험성, 신뢰성이 핵심 |
| 특수 목적 | 다이어프램식 | 특수 오일프리 방식 | 일반 상선보다 특수 가스·오일프리·누설 방지 용도에 제한 적용 |

본 보고서에서 제시하는 압력 범위는 **일반적인 기술 검토용 참고값**이다.  
실제 설계값은 반드시 다음 자료로 확정해야 한다.

- 선급 규칙: KR, DNV, ABS, LR 등
- SOLAS 및 Flag State 요구사항
- 엔진 메이커 프로젝트 가이드: MAN Energy Solutions, Wärtsilä 등
- 조선소 사양서
- 장비 제조사 승인 도면
- Air Receiver 용량 계산서
- 압축공기 충전 시간 계산서

## 3. 제외 범위

## 5. 선박 압축공기 시스템 개요

선박 압축공기 시스템은 기관실과 선내 각종 공압 장비에 압축공기를 공급하는 보조 시스템이다. 특히 대형 디젤 주기관을 사용하는 선박에서는 시동 공기 시스템이 필수이며, 에어 컴프레서와 Air Receiver가 함께 구성된다.

### 5.1 일반 구성 요소

| 구성 요소 | 역할 |
|---|---|
| Air Compressor | 대기 공기를 흡입하여 필요한 압력까지 압축 |
| Air Receiver / Air Bottle | 압축공기 저장 |
| Safety Valve | 과압 발생 시 압력 방출 |
| Pressure Gauge / Pressure Switch | 압력 감시 및 자동 기동·정지 제어 |
| Cooler / Intercooler / Aftercooler | 압축 과정에서 발생한 열 제거 |
| Drain System | 응축수, 오일, 이물질 배출 |
| Filter | 입자, 오일 미스트 제거 |
| Air Dryer | 수분 제거, 계장 공기 품질 확보 |
| Check Valve | 역류 방지 |
| Control Panel | 기동·정지, 알람, 보호 기능 |
| Distribution Line | 각 사용처로 압축공기 분배 |

### 6.1 왕복동식 컴프레서  
#### Reciprocating / Piston Type

왕복동식 컴프레서는 피스톤의 왕복 운동으로 공기를 압축하는 방식이다. 고압 압축에 유리하고 선박 시동 공기 시스템에서 적용 경험이 많아 주기관 및 보조기관 시동용으로 우선 검토된다.

| 항목 | 내용 |
|---|---|
| 기본 구조 | 실린더, 피스톤, 크랭크축, 커넥팅로드, 흡입밸브, 토출밸브 |
| 압력 특성 | 고압 압축에 유리 |
| 유량 특성 | 중소유량 중심 |
| 운전 특성 | 간헐 운전, 고압 충전 운전에 적합 |
| 대표 용도 | 주기관 시동 공기, 보조기관 시동 공기, 비상용 공기 |
| 장점 | 고압 대응 우수, 구조 검증도 높음, 선박 적용 경험 많음 |
| 단점 | 진동·소음 큼,
