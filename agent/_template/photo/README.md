# {에이전트명} — 프로필 사진

`photo/` 폴더에 감정별 이미지를 넣으면 채팅창에 표시됩니다.

| 파일명 | 용도 |
|--------|------|
| `기본.png` | 채팅창 헤더 프로필 (고정) |
| `기쁨.png` | 기쁜/완료 응답 말풍선 |
| `슬픔.png` | 실패·사과 응답 말풍선 |
| `화남.png` | 거부·불만 응답 말풍선 |
| `놀람.png` | 놀라움 응답 말풍선 |
| `걱정.png` | 작업 중·검토 응답 말풍선 |

확장자는 `.png`, `.jpg`, `.webp` 등 이미지 형식을 지원합니다.
감정 파일이 없으면 `기본` 이미지로 대체됩니다.
