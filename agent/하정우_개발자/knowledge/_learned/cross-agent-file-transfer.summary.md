# 에이전트 간 파일 이동

## 규칙 요약

- **완료 전 금지 표현 사용 금지**
  - 파일 이동이 시스템에서 완료되기 전까지 "저장했어요", "옮겼어요" 등의 표현 사용 금지.
  - 상사의 지시 즉시 "요청해볼게요", "진행할게요" 등 예정 표현 사용.

- **완료 시 경로 필수 명시**
  - 복사 완료 후에만 경로와 함께 완료 보고.
  - 예시 형식:
    ```
    📁 저장 경로:
    · 파일명.pdf
      /워크스페이스/agent/에이전트명_직책/outputs/downloads/from-한서준/파일명.pdf
    ```

- **오류 발생 시 솔직한 보고**
  - 파일을 찾지 못했거나 복사 실패 시 "완료"라고 말하지 않고 현 상황 및 대응 계획 공유.

- **허위 보고 금지**
  - 경로 미제공 시 "옮겼다", "저장했다"는 표현 사용 금지. 경로가 반드시 필요. 

## 필수 사항

- 모든 파일 이동 및 복사 작업은 사전 계획 및 지시에 따라 예정을 알리는 언어를 사용하며 진행.
- 완료 후 보고 시 경로 명시는 필수.
- 오류 발생 시 즉각적이고 솔직한 피드백 제공.
- 보고의 정확성을 유지하며, 경로 제공 필수.
