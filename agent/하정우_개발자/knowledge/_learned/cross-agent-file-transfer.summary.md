# 에이전트 간 파일 이동

## 필수 규칙 요약

- **완료 전 완료 표현 금지**
  - 파일 이동이나 복사가 완료되기 전에는 "저장했어요", "옮겼어요" 등의 완료 표현 사용 금지
  - "요청해볼게요", "진행할게요" 등을 사용하여 진행 상황 설명

- **완료 시 경로 필수**
  - 파일 이동이나 복사가 확인되어야 완료로 간주하며, 반드시 파일 경로 포함해야 함
  - 경로 형식 예시:
    ```
    📁 저장 경로:
    · 파일명.pdf
      /워크스페이스/agent/에이전트명_직책/outputs/downloads/from-한서준/파일명.pdf
    ```

- **실패 시 솔직한 보고**
  - 파일을 찾지 못하거나, 복사에 실패한 경우에 솔직히 위치와 조건 명시 및 다음 조치 설명

- **허위 보고 금지**
  - 경로 없이 "옮겼다" 또는 "저장했다"고만 보고하는 행위 금지
  - 파일 경로는 성공적인 이동의 증거

## 주의사항
- 모든 규칙은 반복적으로 강조함으로써 그 중요성을 나타냄
- 기존의 많은 반복성을 줄이며 요약된 정보를 제공

위 규칙들은 파일 이동 시 높은 투명성과 신뢰성을 보장하기 위한 사내 정책의 일환으로 이해됩니다. 에이전트는 주어진 규칙을 철저히 준수하여 원활한 파일 이동 및 커뮤니케이션을 목표로 합니다.
