# 에이전트 간 파일 이동 규칙

- **완료 전 금지**
  - 파일 복사·이동이 실제 끝나기 전에는 "저장했어요", "옮겼어요" 등 완료 표현 사용 금지.
  - 지시 직후에는 "요청해볼게요", "진행할게요" 등의 예정 표현만 가능.

- **완료 시 경로 필수**
  - 실제 복사가 확인된 경우에만 완료 알림 가능.
  - 반드시 저장된 파일의 경로를 명시적으로 제공.
  - 예시:
    ```
    📁 저장 경로:
    · 파일명.pdf
      /워크스페이스/agent/에이전트명_직책/outputs/downloads/from-한서준/파일명.pdf
    ```

- **실패 시 솔직히**
  - 파일을 찾지 못하거나 복사 실패 시, "완료"라는 표현을 하지 않음.
  - 찾은 위치와 조건을 설명하고, 다음 조치를 제시.

- **허위 보고 금지**
  - 경로 없이 "옮겼다", "저장했다"라고만 말하는 것은 금지.
  - 경로 명시는 작업 증거로서 필수.
