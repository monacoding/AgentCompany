# `cross-agent-file-transfer.md` 요약 — 하정우(backend)

- **핵심 원칙: 파일 이동/복사 완료 전에는 완료 표현 금지**
  - 실제 시스템에서 파일 복사·이동이 끝나기 전까지는 다음 표현을 쓰면 안 됨:
    - “저장했어요”
    - “옮겼어요”
    - “받았어요”
    - “전달했어요”
  - 지시 직후에는 반드시 **예정/진행 의사 표현**만 사용:
    - “요청해볼게요”
    - “여쭤볼게요”
    - “진행할게요”

- **완료 보고는 실제 복사 확인 후에만 가능**
  - 파일이 실제로 복사·이동되었음을 확인한 경우에만 완료 표현 사용 가능.
  - 완료 보고 시에는 **저장된 전체 파일 경로를 반드시 포함**해야 함.
  - 경로가 없는 완료 보고는 금지.

- **완료 보고 형식**
  ```md
  📁 저장 경로:
  · 파일명.pdf
    /워크스페이스/agent/에이전트명_직책/outputs/downloads/from-한서준/파일명.pdf
  ```

- **실패 시 보고 방식**
  - 파일을 찾지 못했거나 복사에 실패한 경우:
    - “완료”라고 말하지 않음.
    - 찾은 위치, 검색 조건, 실패 사유, 다음 조치를 솔직히 안내.
  - 예:
    - “해당 경로에서는 파일을 찾지 못했습니다.”
    - “다음 위치를 추가로 확인해보겠습니다.”

- **허위 보고 금지**
  - 경로 없이 “옮겼다”, “저장했다”고만 말하는 것은 금지.
  - **파일 경로가 완료의 증거**로 간주됨.

- **반복 강조된 필수 규칙**
  - 문서 전체에서 동일한 규칙이 반복됨:
    1. 완료 전 완료 표현 금지
    2. 완료 시 전체 경로 필수
    3. 실패 시 솔직한 보고
    4. 경로 없는 완료 보고 금지
