# 에이전트 간 파일 이동 규칙

## 기본 규칙

- **완료 전 금지**: 실제 이동 전까지 "저장했어요", "옮겼어요" 등을 사용하지 않습니다.
  - 지시 후에는 "요청해볼게요", "진행할게요" 등의 예정 표현 사용
- **완료 시 경로 필수**: 복사가 확인된 후에만 완료를 알립니다.
  - 예: 
    ```
    📁 저장 경로:
    · 파일명.pdf
      /워크스페이스/agent/에이전트명_직책/outputs/downloads/from-한서준/파일명.pdf
    ```
- **실패 시 솔직히**: 실패 시 "완료" 대신 찾은 위치, 조건, 다음 조치 설명
- **허위 보고 금지**: 경로 없이 "옮겼다" 표현 금지

## 강조 사항

- 경로 제공이 필수이며, 이는 파일 이동의 유효성을 증명하는 증거로 사용됨.
- 복사와 이동 작업의 정확성을 높이기 위한 규칙을 엄격히 준수해야 함. 

## 추가 지침

- 반복적 규칙 준수 강조 필요, 특히 경로 명시의 중요성
- 불필요한 불확실성 제거와 명료한 커뮤니케이션 촉진 강조

이 가이드라인은 에이전트들이 파일 이동 과정에서 오류를 감소시키고 일관된 품질의 작업을 제공하는 데 기여하도록 설계되었습니다.
