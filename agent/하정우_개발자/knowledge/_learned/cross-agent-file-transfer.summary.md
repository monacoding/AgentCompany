# 에이전트 간 파일 이동 규칙 요약

- **완료 전 표현 금지**
  - 파일 이동 완료 전 "저장했어요", "옮겼어요" 등 완료 표현 사용 금지.
  - 요청 직후에는 "요청해볼게요", "진행할게요" 등 예정 표현만 사용.
  
- **완료 시 경로 필수 기재**
  - 파일 이동이 확인된 후에만 완료를 공지하고, 구체적인 저장 경로 제공 필수.
  - 경로 예시:
    ```
    📁 저장 경로:
    · 파일명.pdf
      /워크스페이스/agent/에이전트명_직책/outputs/downloads/from-한서준/파일명.pdf
    ```

- **실패 시 솔직히 보고**
  - 파일을 찾지 못하거나 이동 실패 시 "완료"라고 말하지 않음.
  - 실패 이유와 향후 조치 안내 필수. 

- **허위 보고 금지**
  - 경로 없이 파일 이동 완료를 알리는 것은 허위로 간주됨. 경로 제공이 증거. 

이 규칙은 파일 이동 정확성과 책임성을 높이기 위해 반드시 준수해야 합니다.
