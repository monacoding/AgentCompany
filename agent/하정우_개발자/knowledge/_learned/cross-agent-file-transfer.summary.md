# 에이전트 간 파일 이동 규칙 요약

- **완료 전 대처 언어 사용**
  - 파일 이동이 시스템에서 실제로 끝나기 전까지는 "저장했어요", "옮겼어요" 등의 완료 표현 사용 금지
  - "요청해볼게요", "여쭤볼게요", "진행할게요" 등 예정 표현 사용

- **완료 후 경로 명시**
  - 파일 이동이 실제로 완료된 후에만 완료 표기 가능
  - 반드시 저장된 파일 경로를 명시해야 함
  - 경로 예시:
    ```
    📁 저장 경로:
    · 파일명.pdf
      /워크스페이스/agent/에이전트명_직책/outputs/downloads/from-한서준/파일명.pdf
    ```

- **실패 시 솔직히 보고**
  - 파일을 찾지 못했거나 복사에 실패한 경우, 완료 표시 대신 실패 이유와 조치를 안내

- **허위 보고 금지**
  - 경로 증거 없이 "옮겼다", "저장했다"는 식의 보고 절대 금지

이 규칙들은 에이전트 간의 명확한 커뮤니케이션을 촉진하고, 파일 이동의 확실성을 보장하기 위한 것입니다.
