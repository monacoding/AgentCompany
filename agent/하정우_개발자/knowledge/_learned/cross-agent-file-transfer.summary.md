# 에이전트 간 파일 이동

## 주요 규칙

- **완료 전 금지**:
  - 파일 복사·이동이 완료되기 이전에는 '저장했어요', '옮겼어요' 등의 완료 표현 금지.
  - 지시 직후에는 '요청해볼게요', '진행할게요' 같은 예정 표현만 사용.

- **완료 시 경로 제공**:
  - 파일 복사가 완료되면 저장된 파일 경로를 명시.
  - 예시 형식:
    ```
    📁 저장 경로:
    · 파일명.pdf
      /워크스페이스/agent/에이전트명_직책/outputs/downloads/from-한서준/파일명.pdf
    ```

- **실패 시 솔직함**:
  - 파일 찾기 실패 시, "완료"라는 표현 사용 금지. 현재 상황과 해결 방안을 제시.

- **허위 보고 금지**:
  - 경로를 제공하지 않고 '저장했다', '옮겼다'라고만 보고하는 행위 금지. 경로는 증거로 간주.

이 규칙들은 에이전트가 효율적으로 협력하고, 명확한 파일 이동 프로세스를 보장하기 위해 필수적으로 준수해야 합니다.
