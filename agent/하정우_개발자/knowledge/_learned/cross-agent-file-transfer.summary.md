# 에이전트 간 파일 이동 규칙

- **완료 전 금지**
  - 파일 복사 및 이동 작업이 완전히 끝나기 전까지 "저장했어요", "옮겼어요" 등의 완료 표현을 사용 금지.
  - 작업 시작 시 "요청해볼게요", "진행할게요" 같은 예정 표현 사용.

- **완료 시 경로 필수**
  - 파일 복사가 완료되었을 때에만 완료 선언. 반드시 파일 저장 경로를 명시해야 함.
  - 경로 형식 예시:
    ```
    📁 저장 경로:
    · 파일명.pdf
      /워크스페이스/agent/에이전트명_직책/outputs/downloads/from-한서준/파일명.pdf
    ```

- **실패 시 솔직히**
  - 파일을 찾지 못하거나 복사 실패 시 '완료'라고 말하지 않으며, 발견된 위치, 조건, 다음 조치에 대해 설명.

- **허위 보고 금지**
  - "옮겼다", "저장했다"등 경로 없이 완료 보고 금지. 경로 제공이 증거로 간주됨.
