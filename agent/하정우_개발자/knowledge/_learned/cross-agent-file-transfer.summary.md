# 에이전트 간 파일 이동 요약

- **완료 전 금지**
  - 파일 이동이 시스템에서 실제로 끝나기 전까지 "저장했어요", "옮겼어요" 같은 완료 표현 금지.
  - 실시 전: "요청해볼게요", "진행할게요" 등의 예정 표현 사용.

- **완료 시 경로 필수**
  - 이동 완료 후에는 저장된 모든 파일 경로를 명확히 명시.
  - 형식:
    ```
    📁 저장 경로:
    · 파일명.pdf
      /워크스페이스/agent/에이전트명_직책/outputs/downloads/from-한서준/파일명.pdf
    ```

- **실패 시 솔직히**
  - 파일을 찾거나 복사 실패 시 "완료"란 표현 금지.
  - 현재 상황, 찾은 위치, 다음 조치 방안 안내 필수.

- **허위 보고 금지**
  - 경로 없이 "옮겼다", "저장했다" 등의 보고는 금지.
  - 경로가 곧 증거로 간주됨.
