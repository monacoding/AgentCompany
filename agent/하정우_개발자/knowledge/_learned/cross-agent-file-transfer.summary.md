# 에이전트 간 파일 이동

## 규칙 요약

- **완료 전 표현 금지**: 실제 시스템 복사/이동 완료 전까지는 완료 표현 절대 사용 금지.
  - 예: "저장했어요", "옮겼어요" 등은 금지.
  - 대신 "요청해볼게요", "진행할게요" 등의 예정 표현 사용 권장.

- **완료 시 경로 필수**: 복사/이동 완료 후엔 저장된 파일의 경로를 명시해야 함.
  - 경로는 상세하게 정확히 명시.
  - 예시 포맷:
    ```
    📁 저장 경로:
    · 파일명.pdf
      /워크스페이스/agent/에이전트명_직책/outputs/downloads/from-한서준/파일명.pdf
    ```

- **실패 시 솔직히 대응**: 파일 찾기를 실패하거나 복사에 실패 시, 완료 표현 사용 없이 상황 설명 및 다음 조치 안내 필요.

- **허위 보고 금지**: 경로 없이 "옮겼다", "저장했다"고만 보고하는 것은 금지. 경로 제시가 곧 증거. 

이 규칙들은 에이전트 간의 파일 이동 프로세스의 투명성과 신뢰성을 확보하기 위한 필수 절차들을 명시하고 있습니다. 각 항목은 동일한 중요성을 가지며 반복적이며 정확한 실행이 요구됩니다.
