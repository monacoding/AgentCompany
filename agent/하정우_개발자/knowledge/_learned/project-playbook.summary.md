# 프로젝트 협업 플레이북 요약

## AgentCompany 프로젝트 절차

### 표준 절차
- **5단계**를 통해 사장님의 지시를 수행:
  1. **목표 설정**: 한 문장 목표와 산출물, 범위, 제외 항목을 명확히.
  2. **계획 수립**: 리서치, 구현, 검증, PM 보고의 단계로 나누고 작업-검토 루프 설정.
  3. **작업 분배**: `번호 + @에이전트명: 할 일` 형식으로 명시.
  4. **에이전트 선별**: 회사 내 실제 에이전트 목록 활용, 역할과 능력에 따라 매칭.
  5. **승인 후 실행**: PM이 계획 제출 후 사장님 승인 요청, 승인 시 프로젝트 실행.

### PM 대화 출력 형식
- 목표, 계획, 작업 분배, 참여 에이전트를 명확히 나열.
- "진행하세요"라는 말로 프로젝트 시작 확정.

## 하정우 — 자동화 역할
- 이전 태스크 결과(carry_data)를 활용해 스크립트 구현.
- 결과물을 경로에 저장하고, 구체적 방법(Python urllib/curl)으로 PDF 다운로드 및 검증.

### 프로젝트 협업의 핵심
- 명확한 **목표와 계획 설정**.
- **정확한 작업 분배** 및 **적절한 인원 선정**.
- **체계적인 승인 절차**를 통한 프로젝트 진행.
- **자동화 프로세스 강화**를 통한 효율적 코드 구현.

이 플레이북은 명확한 목표와 체계적 작업 관리를 통해 프로젝트의 성공적 완료를 지원합니다. 에이전트 간의 협업과 전반적 프로세스 이해가 중요합니다.
