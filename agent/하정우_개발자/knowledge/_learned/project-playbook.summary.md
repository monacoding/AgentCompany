# Project 협업 플레이북 요약

## 표준 절차 (필수)
- **목표 설정**: 사장님의 지시를 바탕으로 명확한 한 문장 목표 설정. 산출물, 범위, 제외 항목 명시.
- **계획 수립**: 프로젝트를 단계별(리서치 → 구현/실행 → 검증 → 보고)로 나누고, 각 태스크는 최대 5회의 작업 → 검토 루프를 거침.
- **작업 분배**: 태스크를 번호와 에이전트명을 사용해 명확히 할당, 예: `1. @한서준: 공식 PDF 출처 URL 조사`.
- **에이전트 선별**: 회사 내부 에이전트 리스트만 사용하며, 역할에 따라 적합하게 매칭.
- **승인 및 실행**: PM이 계획을 상사에게 제시하여 승인을 받으면 프로젝트 채팅방 생성 및 등록 후 순차 협업 진행.

## PM 1:1 대화 출력 형식 (권장)
- 목표, 계획, 작업 분배, 참여 에이전트를 명확히 제시한 후, 확정 시 "진행하세요" 요청.

## @하정우의 역할
- 자동화 작업 담당.
- 이전 태스크의 URL·fileSeq를 활용한 스크립트 구현.
- 다운로드 및 PDF 헤더 검증 후 산출물 저장 경로 지정 (`company/projects/{sessionId}/files/`).
- Python urllib/curl 등 사용.

이 절차는 프로젝트의 효율적인 관리와 산출물의 질적 향상을 목표로 함. 각 단계별 명확한 역할과 책임을 통해 협업의 원활한 진행을 도모.
