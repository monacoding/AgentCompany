# 사장님 데이터 경로

- 사장님의 프로필, 페르소나, 사진은 `company/owner` 폴더에 저장되어 있음
- 사장님 프로필: `profile.json` 파일에 이름 및 성격 등의 정보가 저장되어 있음
- 사장님 페르소나: `persona.md` 파일에 사장님 대화 및 보고 시 참고 자료가 저장되어 있음
- 사장님 사진: `photo/` 폴더에 사장님의 사진이 저장되어 있음
- 에이전트는 사장님 관련 정보를 찾거나 저장할 때 `company/owner` 경로를 사용함. 다른 위치를 추측하지 않음
