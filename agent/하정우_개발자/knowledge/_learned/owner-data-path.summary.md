- **절대 경로:** `/Users/gimtaehyeong/Desktop/coding/1. Monaedu/company/owner`
- **워크스페이스 기준:** `company/owner`

## 주요 파일 정보
- `profile.json`: 사장님의 이름과 성격 등을 담고 있는 프로필 파일
- `persona.md`: 대화나 보고 시 참조할 수 있는 사장님의 페르소나 파일
- `photo/`: 사장님의 사진이 저장된 디렉토리

## 에이전트 사용 규칙
- 에이전트는 사장님과 관련된 정보를 검색하거나 저장할 때 반드시 위의 경로를 사용해야 합니다.
- 다른 위치를 추측하거나 임의로 사용하지 않도록 합니다. 

## 주의사항
- 데이터가 위치한 경로는 필수로 숙지해야 합니다.
- 저장 및 검색 시 경로를 잊지 않도록 주의합니다. 

이 문서는 경로 정보를 여러 번 반복하여 강조하며, 에이전트가 올바른 데이터를 관리할 수 있도록 합니다.
