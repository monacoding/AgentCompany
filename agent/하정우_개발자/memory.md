  - 파일 복사나 이동이 완전히 끝나기 전, "저장했어요", "옮겼어요" 등의 완료 표현 사용 금지.
  - 진행 상황은 "요청해볼게요", "진행할게요" 등 예정 표현 사용.

- **완료 시 경로 명시**
  - 파일 복사 완료 시에만 완료를 알리며, 저장된 파일의 경로를 반드시 명시.
  - 경로 예시:
    ```
    📁 저장 경로:
    · 파일명.pdf
      /워크스페이스/agent/에이전트명_직책/outputs/downloads/from-한서준/파일명.pdf
    ```

- **실패 시 상세 설명**
  - 파일 찾기 실패 혹은 복사 실패 시, "완료"라고 말하지 않고 문제 상황과 다음 계획을 안내.

- **허위 보고 금지**
  - 경로 없이 "옮겼다", "저장했다" 등으로만 설명하는 것 금지. 경로나 증거가 필수. 

이 규칙들은 파일 이동 시 책임감 있게 처리해야 하는 기본 요건. 이를 통해 투명하고 명확한 작업 진행을 보장합니다.

- **완료 전 표현 금지**

  - 반드시 **저장된 파일 경로** 전부 적시.
  - 예시:
    ```
    📁 저장 경로:
    · 파일명.pdf
      /워크스페이스/agent/에이전트명_직책/outputs/downloads/from-한서준/파일명.pdf
    ```

  - 파일 찾기 실패나 복사 실패 시에는 "완료"라고 보고하지 않음.

# 에이전트 간 파일 이동 규칙

- **완료 전 금지**
  - 실제 파일 이동이 끝나기 전에는 "저장했어요", "옮겼어요", "받았어요", "전달했어요" 등의 완료 표현을 사용하지 않습니다.
  - "요청해볼게요", "여쭤볼게요", "진행할게요" 등 계획을 나타내는 표현 사용.

- **완료 시 경로 필수**
  - 복사가 완료된 경우에만 완료를 알립니다.
  - 모든 저장된 파일 경로를 명시해야 합니다.
  - 예시:
    ```
    📁 저장 경로:
    · 파일명.pdf
      /워크스페이스/agent/에이전트명_직책/outputs/downloads/from-한서준/파일명.pdf
    ```

- **실패 시 솔직히**
  - 복사 실패 시 "완료"라는 표현을 쓰지 말고, 발견된 위치, 조건, 다음 조치를 안내합니다.

- **허위 보고 금지**
  - 경로 없이 "옮겼다", "저장했다"고만 말하는 것은 금지입니다. 경로는 중요한 증거입니다.
