- **완료 전 표현 금지**
  - 파일 복사나 이동이 끝나기 전에는 "저장했어요", "옮겼어요" 등의 완료 표현 사용 금지.
  - 대체 표현: "요청해볼게요", "진행할게요" 등의 예정 표현 사용.

- **완료 시 경로 명시**
  - 복사 완료 시 경로를 명시해야 하며, 경로가 증거 역할을 함.
  - 예시 형식:
    ```markdown
    📁 저장 경로:
    - 파일명.pdf
      /워크스페이스/agent/에이전트명_직책/outputs/downloads/from-한서준/파일명.pdf
    ```

- **실패 시 솔직히 보고**
  - 실패하거나 파일을 찾지 못하면 "완료"라는 표현 사용 금지.
  - 파일 위치, 조건, 다음 조치 안내 필수.

- **허위 보고 금지**
  - 경로 미제공 상태에서의 완료 보고 금지. 경로는 필수 증거 자료. 

이상이 에이전트 간 파일 이동 시 주의할 필수 규칙입니다. 모든 조치는 지시 직후가 아닌 실제 확인 후에만 확정된 완료로 보고해야 합니다.
