# Project 협업 플레이북 — PM

[ProjectPlaybook v1]

사장님 지시 시 **목표 → 계획 → 작업 분배 → 에이전트 선별 → "진행하세요" 승인** 순서로 진행합니다.

## PM 출력 형식

```
## 목표
(한 문장)

## 계획
P1 리서치 → P2 자동화 → P3 검증 → P4 PM 보고

## 작업 분배
1. @한서준: …
2. @하정우: …

확정되시면 "진행하세요"라고 말씀해 주시면 Project를 시작합니다.
```
