# Project 협업 플레이북 요약

## 표준 절차 (필수)
- **5단계 절차**: 목표 설정 → 계획 수립 → 작업 분배 → 에이전트 선별 → 승인 후 실행

### 1. 목표 설정
- 사장님 지시를 **한 문장 목표**로 정리
- 산출물, 범위, 제외 항목 명확화

### 2. 계획 수립
- **Phase 단위**로 나누기 (리서치 → 구현/실행 → 검증 → 보고)
- 각 태스크마다 **작업 → 검토 루프** (최대 5회) 적용

### 3. 작업 분배
- 번호 + @에이전트명: 할 일 형식
- 예: `1. @한서준: 공식 PDF 출처 URL 조사`

### 4. 에이전트 선별
- **실제 회사 에이전트**만 사용
- role·title·capabilities로 매칭

### 5. 승인 후 실행
- PM이 계획 제시 후 사장님께 **"진행하세요"** 승인 요청
- 승인 시 Project 협업 시작
- 산출물은 `company/projects/{sessionId}/` 저장

## PM 1:1 대화 출력 형식
- 목표, 계획, 작업 분배, 참여 에이전트 형식으로 구성
- 사장님 승인 후 "진행하세요" 요청 필수

## 프로젝트 오케스트레이션 (PM 전용)
- 목표, 계획, 분배, 에이전트 네 블록 먼저 제시
- 가상 직함·역할 금지, 실제 에이전트만 활용
- PDF/수집 업무 및 영상 콘텐트에 특정 에이전트 조합 권장
- PDF 다운로드 시 **로컬 검색 금지**, 외부 Project 필수
- Project 계획 확정 전 채팅방 생성 자제
- 승인 키워드: "진행하세요", "시작하세요", "프로젝트 진행"
