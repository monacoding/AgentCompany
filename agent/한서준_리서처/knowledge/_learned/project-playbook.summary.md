# Project 협업 플레이북

## AgentCompany Project 표준 절차 (필수)

### 1. 목표
- 사장님 지시에서 **한 문장 목표** 설정
- 산출물, 범위, 제외 항목 명확히 설정

### 2. 계획
- Phase 단위 구분: 리서치 → 구현/실행 → 검증 → PM 보고
- 각 태스크: 작업 → 검토 루프 최대 5회, FINISHED 키워드 활용

### 3. 작업 분배
- **번호 + @에이전트명: 할 일** 형식으로 작성
- 예: `1. @한서준: 공식 PDF 출처 URL 조사`

### 4. 에이전트 선별
- **실제 회사 에이전트**만 사용, 가상 직함·외부 인력 금지
- 역할, 직함, 역량 매칭 (리서치→researcher, 자동화→backend, 도메인→전문가)

### 5. 승인 후 Project 실행
- PM이 계획 제시 후 **"진행하세요"** 승인 요청
- 승인 시: Project 채팅방 생성 → Projects 탭 등록 → 에이전트 순차 협업
- 산출물 저장: `company/projects/{sessionId}/` (tasks/, files/, PM_REPORT.md)
- 이전 태스크 산출물은 **carry_data**로 다음 태스크 전달

## PM 1:1 대화 출력 형식 (권장)

```
## 목표
(한 문장)

## 계획
P1 … / P2 … / P3 …

## 작업 분배
1. @에이전트명: 할 일
2. @에이전트명: 할 일

## 참여 에이전트
@박준호 · @한서준 · …

확정되시면 "진행하세요"라고 말씀해 주시면 Project를 시작합니다.
```

## PM 전용 — Project 오케스트레이션

- 사장님 지시 수신 후 **목표·계획·분배·에이전트** 4블록 우선 제시
- roster에 없는 인물·역할 생성 금지
- PDF/수집 업무: @한서준(출처) → @하정우(스크립트) → 도메인 전문가(검증)
- 영상/콘텐츠: @서윤아델린 + @하정우 조합 검토
- 계획 확정 전 Project 채팅방 열지 않음
- 승인 키워드: "진행하세요", "시작하세요", "프로젝트 진행"
