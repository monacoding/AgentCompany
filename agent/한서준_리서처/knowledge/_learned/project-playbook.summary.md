# Project 협업 플레이북 요약

## AgentCompany Project 표준 절차

- 사장님 지시 후 **5단계** 진행.
- 각 단계: 목표 설정, 계획 수립, 작업 분배, 에이전트 선별, 승인 후 실행.

### 1. 목표 설정
- 사장님 지시에서 **한 문장 목표** 정의.
- 산출물과 범위, 제외 항목 명확히.

### 2. 계획 수립
- Phase 단위로 진행: 리서치 → 구현/실행 → 검증 → PM 보고.
- 각 태스크 **작업 → 검토 루프**(최대 5회) 실행, FINISHED 키워드 사용.

### 3. 작업 분배
- 계획 문서에 **번호 + @에이전트명: 할 일**로 작업 분배.
- 예: `1. @한서준: 공식 PDF 출처 URL 조사`.

### 4. 에이전트 선별
- **실제 회사 roster**만 사용, 가상 직함 및 외부 인력 금지.
- role과 title, capabilities로 매칭.

### 5. 승인 후 Project 실행
- PM이 사장님께 계획 제시 후 **"진행하세요"** 요청.
- 승인 후: Project 채팅방 생성, Projects 탭 등록, 에이전트 협업.
- 산출물 저장: `company/projects/{sessionId}/`.
- 이전 태스크 산출물은 **carry_data**로 전달.

## PM 1:1 대화 출력 형식

```
## 목표
(한 문장)

## 계획
P1 … / P2 … / P3 …

## 작업 분배
1. @에이전트명: 할 일
2. @에이전트명: 할 일

## 참여 에이전트
@박준호 · @한서준 · …

확정 후 "진행하세요" 입력 시 Project 시작.
```

## PM 전용 — Project 오케스트레이션

- 사장님 지시 수신 후 **목표·계획·분배·에이전트** 블록 제시.
- roster에 없는 인물·역할 금지.
- PDF 수집 업무: @한서준 → @하정우 → 도메인 전문가.
- 영상/콘텐츠: @서윤아델린 + @하정우 검토.
- Project 채팅방은 계획 확정 후에만 생성.
- 승인 키워드: "진행하세요", "시작하세요", "프로젝트 진행".
