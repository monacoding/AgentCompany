# Project 협업 플레이북 요약

## AgentCompany Project 표준 절차 (필수)

### 1. 목표 설정
- 사장님 지시에서 **한 문장 목표** 파악
- 산출물, 범위, 제외 항목 명확화

### 2. 계획 수립
- 프로젝트를 Phase 단위로 나누기 (리서치 → 구현/실행 → 검증 → 보고)
- **작업 → 검토 루프** 최대 5회 반복 (FINISHED 키워드)

### 3. 작업 분배
- **번호 + @에이전트명: 작업 내용**으로 작업 분배
- 예시: `1. @한서준: 공식 PDF 출처 URL 조사`

### 4. 에이전트 선별
- **실제 에이전트 roster**만 사용
- 역할과 직무에 맞춰 매칭 (리서치→researcher, 자동화→backend 등)

### 5. 승인 후 프로젝트 실행
- PM이 계획을 사장님께 보고하고 승인 요청
- 승인 후: 프로젝트 채팅방 생성, Projects 탭 등록, 순차 협업 진행
- 산출물 저장 경로: `company/projects/{sessionId}/`
- 이전 태스크 산출물은 **carry_data**로 전달

## PM 1:1 대화 출력 형식 (권장)

- 목표, 계획, 작업 분배, 참여 에이전트를 형식에 맞춰 기술
- "진행하세요"를 통해 프로젝트 시작

## PM 전용 — Project 오케스트레이션

- 사장님 지시 수신 후 **목표, 계획, 분배, 에이전트** 4블록 제시
- roster에 없는 인물 또는 역할 생성 금지
- **PDF/수집 업무 진행 흐름**: @한서준(출처) → @하정우(스크립트) → 도메인 전문가(검증)
- 영상/콘텐츠 팀: @서윤아델린 + @하정우 조합
- 계획 확정 전에는 프로젝트 채팅방 열지 않음
- 승인 키워드: "진행하세요", "시작하세요", "프로젝트 진행"

## 주의사항
- 모든 PDF 다운로드 요청은 외부 수집 Project로 계획해야 하며, 내부 knowledge/·로컬 파일 검색 금지
- 계획 확정 전, 프로젝트 채팅방을 미리 생성하지 않음

이 가이드라인은 PM이 프로젝트 진행을 효율적으로 관리하고 순조롭게 협업할 수 있도록 돕습니다.
