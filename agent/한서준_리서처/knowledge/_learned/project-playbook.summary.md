# 프로젝트 협업 플레이북 요약

## 기본 절차

- 사장님 지시에 따라 프로젝트는 **5단계**로 진행.
  1. **목표 설정**: 한 문장 목표 및 산출물, 범위, 제외 항목 명확히.
  2. **계획 수립**: 단계적 구분(리서치 → 구현/실행 → 검증 → 보고).
  3. **작업 분배**: `번호 + @에이전트명: 할 일` 형식으로 구체화.
  4. **에이전트 선별**: 회사 목록내 인물만 지정, 역할에 맞는 에이전트 선택.
  5. **승인 후 실행**: 계획 승인 요청 후에 프로젝트 시작.

## 프로젝트 수행 지침

- 사장님 지시 수신 시 **목표, 계획, 작업 분배, 에이전트**를 먼저 제시.
- PDF 및 수집 업무는 특정 에이전트(@한서준, @하정우, 도메인 전문가) 순으로 배치.
- 계획 승인 전에는 프로젝트 채팅방 생성 불가.
- 승인 키워드: "진행하세요", "시작하세요", "프로젝트 진행".

## PM 대화 형식 예시

```markdown
## 목표
(한 문장)

## 계획
P1 … / P2 … / P3 …

## 작업 분배
1. @에이전트명: 할 일
2. @에이전트명: 할 일

## 참여 에이전트
@박준호 · @한서준 · …

확정되시면 "진행하세요"라고 말씀해 주시면 Project를 시작합니다.
```

## 중요 규칙

- 인터넷/웹 PDF는 knowledge/·로컬 폴더 검색 금지, 외부 수집 프로젝트로 처리.
- 가상 직함·외부 인력 사용 금지.
- 프로젝트 산출물은 carry_data로 다음 태스크에 전달.

### 영상/콘텐츠 조합
- @서윤아델린 + @하정우 조합으로 검토.

이 문서는 프로젝트 관리를 위한 표준 절차와 권장 지침을 제공하며, PM은 이 지침을 따라 프로젝트 효율성을 극대화해야 합니다.
