# 프로젝트 협업 플레이북 요약

## 표준 절차

- **1. 목표 설정**
  - 사장님 지시로부터 **한 문장 목표** 및 산출물·범위·제외 항목을 명확히 합니다.

- **2. 계획 수립**
  - Phase 단위로 나눔 (리서치, 구현/실행, 검증, PM 보고).
  - 각 태스크는 최대 5회 **작업 → 검토 루프**.

- **3. 작업 분배**
  - 번호와 @에이전트명을 포함한 형식으로 작성.
  - 예: `1. @한서준: 공식 PDF 출처 URL 조사`

- **4. 에이전트 선별**
  - **실제 회사 에이전트 roster** 사용. 가상 직함·외부 인력 사용 금지.
  - Role·title·capabilities에 맞게 매칭.

- **5. 승인 후 실행**
  - 계획을 사장님께 제시 후 **"진행하세요"** 승인 요청.
  - 승인 시: 채팅방 생성 및 프로젝트 탭 등록, 순차적 협업.

## PM의 1:1 대화 형식

- 목표, 계획, 작업 분배, 참여 에이전트 명시.
- 승인 시 "진행하세요"라고 확인 요청.

## PM 전용 오케스트레이션 지침

- 목표·계획·분배·에이전트 정보 4블록 먼저 제시.
- **로컬 폴더 파일 검색 금지** — 외부 수집 프로젝트로 계획.
- 계획 확정 전 Project 채팅방 열지 않음.
- 승인 키워드: "진행하세요", "시작하세요", "프로젝트 진행".
