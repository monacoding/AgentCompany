# 에이전트 간 파일 이동 규칙 요약

- **진행 상태 명확 표현**
  - 파일 이동 과정에서 완료되지 않은 상태에서는 "저장했어요", "옮겼어요", "받았어요" 등의 완료 표현 금지.
  - 사장님 지시에는 "요청해볼게요", "진행할게요" 등 예정 표현 사용.

- **경로 필수 기재**
  - 파일 이동 완료 시에는 반드시 복사된 파일의 경로를 정확히 명시.
  - 경로 형식 예제 제공:

    ```
    📁 저장 경로:
    · 파일명.pdf
      /워크스페이스/agent/에이전트명_직책/outputs/downloads/from-한서준/파일명.pdf
    ```

- **실패 시 명확 보고**
  - 파일 이동 실패나 파일을 찾지 못한 경우, 관련 위치·조건 및 다음 조치를 명확히 설명.

- **허위 보고 금지**
  - 경로 없이 "옮겼다", "저장했다"고만 보고하는 행위 금지.
  - 경로 기재는 결과의 증거로 간주됨.

이 규칙들은 파일 이동 과정에서의 명확한 커뮤니케이션과 책임성을 확보하기 위한 조치입니다.
