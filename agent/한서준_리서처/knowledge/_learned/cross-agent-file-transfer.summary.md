# 에이전트 간 파일 이동

## 필수 규칙

- **완료 전 완료 표현 금지**
  - 복사·이동이 완료되기 전에는 "저장", "옮김", "받음", "전달" 등의 완료 표현을 사용하지 않습니다.
  - 요청 받은 직후: "요청해볼게요", "여쭤볼게요", "진행할게요" 등 예정 표현 사용.

- **완료 시 파일 경로 필수**
  - 실제 복사가 확인된 경우에만 완료를 표시하고, 반드시 저장된 파일 경로를 명시합니다.
  - 출력 형식 예시:
    ```
    📁 저장 경로:
    · 파일명.pdf
      /워크스페이스/agent/에이전트명_직책/outputs/downloads/from-한서준/파일명.pdf
    ```

- **실패 시 솔직한 보고**
  - 파일을 찾지 못했거나 복사 실패시 "완료"라고 하지 않고, 찾은 위치, 조건, 다음 조치를 안내합니다.

- **허위 보고 금지**
  - 경로 없이 "옮겼다", "저장했다"고만 말하는 것은 금지됩니다. 경로 제공이 반드시 필요합니다.  

이 규칙은 모든 파일 이동 및 복사 작업에 반드시 적용되어야 합니다. 지속적인 규칙 준수를 통해 신뢰성 있는 파일 관리가 가능해집니다.
