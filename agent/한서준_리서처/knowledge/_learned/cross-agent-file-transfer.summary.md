# 에이전트 간 파일 이동 규칙

## 주요 규칙

- **완료 전 표현 금지**
  - 시스템에서 파일 복사·이동이 실제로 완료되기 전에 "저장했어요", "옮겼어요", "받았어요" 등 완료 표현 사용 금지.
  - 지시 직후에는 "요청해볼게요", "여쭤볼게요" 등 예정 표현 사용.

- **실제 완료 시 경로 필수 제공**
  - 파일 복사가 실제로 완료된 경우에만 완료 표현 사용 가능.
  - 파일이 저장된 전체 경로 반드시 제공.
  - 예시:
    ```
    📁 저장 경로:
    · 파일명.pdf
      /워크스페이스/agent/에이전트명_직책/outputs/downloads/from-한서준/파일명.pdf
    ```

- **실패 시 솔직한 정보 제공**
  - 파일 찾기 실패 혹은 복사 실패 시, 완료 표현 금지.
  - 파일의 위치·조건·다음 조치를 구체적으로 안내.

- **허위 보고 절대 금지**
  - 경로 없이 "옮겼다", "저장했다"는 표현 사용 금지.
  - 경로 정보는 성공적인 파일 이동의 증거.

## 강조사항

- 이 규칙은 에이전트 간의 모든 파일 이동에 필수적이며, 반복되어 강조됨.
- 규칙 위반 시에 발생하는 문제를 방지하기 위함.
- 명확한 파일 위치 정보를 제공함으로써 의사소통 효율성을 높임.
