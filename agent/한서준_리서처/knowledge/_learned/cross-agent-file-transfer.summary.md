# 에이전트 간 파일 이동 규칙

## 기본 규칙

- **완료 전 금지**  
  - 파일 복사 또는 이동이 시스템상 완료되기 전에는 완료 표현을 사용해선 안 됩니다.
  - 사장님 지시 직후에는 "요청해볼게요", "여쭤볼게요", "진행할게요" 같은 **예정** 표현만 사용합니다.

- **완료 시 경로 필수**  
  - 파일 복사가 실제로 완료되었음을 확인한 후에만 완료를 알리며, 저장된 파일의 경로를 모두 명시해야 합니다.
  - 예시 형식:
    ```
    📁 저장 경로:
    · 파일명.pdf
      /워크스페이스/agent/에이전트명_직책/outputs/downloads/from-한서준/파일명.pdf
    ```

- **실패 시 솔직히**  
  - 실패 시에는 "완료"라고 말하지 않고, 찾은 위치, 조건 및 이어질 조치를 제공합니다.

- **허위 보고 금지**  
  - 경로 없이 "옮겼다", "저장했다" 등의 표현만 사용하는 것은 금지됩니다. 경로가 보고의 증거로 사용됩니다.

이 규칙이 **반복**되어 강조되고 있지만, 강력하게 적용되어야 한다는 의미로 간주할 수 있습니다. 각 절차에서 확실한 확인 및 완벽한 투명성을 유지해야 합니다.
