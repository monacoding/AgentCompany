# 에이전트 간 파일 이동

## 파일 이동 규칙

- **완료 전 표현 금지**
  - 파일 이동이 실제로 완료되기 전에는 완료 표현 사용 금지.
  - "요청해볼게요", "진행할게요" 등 예정 표현 사용.

- **완료 시 경로 명시**
  - 파일이 성공적으로 이동된 경우에만 완료 표현 사용.
  - 반드시 저장된 파일의 경로 명시:
    ```
    📁 저장 경로:
    · 파일명.pdf
      /워크스페이스/agent/에이전트명_직책/outputs/downloads/from-한서준/파일명.pdf
    ```

- **실패 시 솔직 보고**
  - 실패 시 완료 표현 사용하지 않음.
  - 찾은 위치, 조건 및 다음 조치를 명확히 안내.

- **허위 보고 금지**
  - 경로 없이 "옮겼다", "저장했다" 표현 금지.
  - 경로가 증거 역할 수행.
