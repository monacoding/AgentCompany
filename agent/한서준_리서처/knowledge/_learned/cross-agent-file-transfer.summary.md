# 에이전트 간 파일 이동 규칙

## 주요 규칙

- **완료 전 금지**  
  - 파일 복사․이동이 완료되기 전에는 완료된 것처럼 표현하지 않습니다.
  - "요청해볼게요", "진행할게요" 등 **예정** 상태를 나타내는 표현을 사용합니다.

- **완료 시 경로 필수**  
  - 복사 완료 후에는 반드시 파일의 저장 경로를 작성하여 완료를 알립니다.
  - 경로 형식 예시:
    ```markdown
    📁 저장 경로:
    · 파일명.pdf
      /워크스페이스/agent/에이전트명_직책/outputs/downloads/from-한서준/파일명.pdf
    ```

- **실패 시 솔직히**  
  - 복사에 실패하거나 파일을 찾지 못한 경우, 상황을 설명하고 다음 조치를 안내합니다.

- **허위 보고 금지**  
  - 경로 없이 "옮겼다", "저장했다"라는 용어 사용 금지. 경로는 필수 증거입니다.

## 추가 참고 사항

- 각 단계에서 **정확한 상태**를 보고하여 커뮤니케이션의 신뢰를 유지합니다.
- 지시 직후에는 **계획 및 진행 상황을 명확히** 전달합니다.
- 시스템 상태를 항상 정확하게 파악하여 **최종 작업 완료 시점**을 명확히 합니다.
