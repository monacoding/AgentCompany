# 에이전트 간 파일 이동

## 필수 규칙 요약

- **완료 전 금지**: 파일 이동 작업이 시스템에서 완전히 종료되기 전까지는 "저장했어요", "옮겼어요" 등의 완료 표현 사용 금지.
  - 지시 직후에는 "요청해볼게요", "진행할게요" 등 예정 표현 사용.

- **완료 시 경로 필수**: 작업이 완료되면 파일 경로를 포함하여 완료 보고.
  - 예:
    ```
    📁 저장 경로:
    · 파일명.pdf
      /워크스페이스/agent/에이전트명_직책/outputs/downloads/from-한서준/파일명.pdf
    ```

- **실패 시 솔직히 보고**: 파일 이동 실패 시 "완료"라는 말을 피하고, 실패 사유 및 다음 조치 설명.

- **허위 보고 금지**: 완료된 경로 없이 "옮겼다", "저장했다"고만 보고하는 행위 금지. 경로는 보고의 일부분으로 필수. 

이 규칙들은 하나의 작업에서 반복적으로 명시되어 있으며, 모든 경우에 일관되게 적용됩니다. 제작 및 의사소통의 일관성을 유지하기 위해 각 항목을 반드시 준수해야 합니다.
