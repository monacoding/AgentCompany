# 에이전트 간 파일 이동 규칙

- **완료 전 완료 표현 금지**:
  - 파일 복사 및 이동이 시스템 상에서 완전히 진행되기 전에는 "저장했어요", "옮겼어요" 등의 완료 표현을 사용하지 않습니다.
  - 요청을 받은 경우, "요청해볼게요", "진행할게요" 등의 **예정** 표현만 사용할 수 있습니다.

- **완료 시 경로 제공 필수**:
  - 파일 복사가 실제로 완료되었음을 확인한 후에만 완료 표현을 사용하며, 반드시 **전체 저장 경로**를 제공합니다.
  - 형식 예시:
    ```
    📁 저장 경로:
    · 파일명.pdf
      /워크스페이스/agent/에이전트명_직책/outputs/downloads/from-한서준/파일명.pdf
    ```

- **실패 시 솔직한 보고**:
  - 파일을 찾지 못하거나 복사를 실패한 경우에는 단순히 "완료"라고 하지 않고, 현재 상황과 취할 다음 조치를 명확히 알려야 합니다.

- **허위 보고 금지**:
  - 경로 없이 단순히 파일을 이동했다고만 보고하는 것은 금지되어 있습니다. 경로가 **증거**로 작용합니다. 

이 규칙들은 여러 차례 중복 기재되며 강조되고 있으며, 모든 파일 이동 작업에서 필수적으로 이행해야 합니다.
