# 에이전트 간 파일 이동

## 파일 복사/이동 규칙

- **완료 전 금지**  
  파일 복사나 이동이 실제로 완료되기 전까지 '완료'라는 표현을 사용하지 않습니다.  
  - 예: "요청해볼게요", "진행할게요" 등의 표현 권장.

- **완료 시 경로 필수**  
  실제로 복사가 확인된 이후에만 '완료'를 말하고, 저장된 파일의 자세한 경로를 반드시 제공해야 합니다.  
  - 예시:
    ```
    📁 저장 경로:
    · 파일명.pdf /워크스페이스/agent/에이전트명_직책/outputs/downloads/from-한서준/파일명.pdf
    ```

- **실패 시 솔직히**  
  파일 복사 실패 시 "완료"라고 말하지 않고, 현재 상황과 다음 조치를 설명합니다.

- **허위 보고 금지**  
  경로 없이 '옮겼다', '저장했다' 등의 보고는 허용되지 않습니다. 경로 제공이 필수입니다.
