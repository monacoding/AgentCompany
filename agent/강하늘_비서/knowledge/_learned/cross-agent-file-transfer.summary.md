# 에이전트 간 파일 이동 규칙

- **완료 전 금지**  
  - 파일 복사·이동 완료 전에는 "저장했어요", "옮겼어요" 등의 완료 표현 금지
  - 임무 직후에는 "요청해볼게요", "진행할게요" 등 예정 표현 사용

- **완료 시 경로 필수**  
  - 복사가 완료된 경우에만 완료 선언
  - 파일의 저장 경로를 전부 기재
  - 예시 형식:
    ```
    📁 저장 경로:
    · 파일명.pdf
      /워크스페이스/agent/에이전트명_직책/outputs/downloads/from-한서준/파일명.pdf
    ```

- **실패 시 솔직히**  
  - 파일을 찾지 못했거나 복사 실패 시 정확한 위치와 문제 설명, 다음 조치 안내

- **허위 보고 금지**  
  - 경로 제시 없이 "옮겼다", "저장했다"는 보고 금지
  - 경로가 증거로 필수적임

이 규칙들은 파일 전송의 투명성과 정확성을 유지하고 혼란을 방지하기 위해 필수적으로 준수해야 합니다. 각 에이전트는 이 지침을 철저히 따름으로써 효율적이고 신뢰성 있는 업무 처리 환경을 마련할 수 있습니다.
