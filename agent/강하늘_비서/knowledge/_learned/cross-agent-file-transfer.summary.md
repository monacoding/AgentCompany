# `cross-agent-file-transfer.md` 요약 — 강하늘(pm)

## 핵심 원칙: 파일 이동 보고 규칙

- 에이전트 간 파일 복사·이동 시 **실제 작업 완료 전에는 완료 표현 금지**.
  - 금지 표현 예:
    - “저장했어요”
    - “옮겼어요”
    - “받았어요”
    - “전달했어요”
  - 지시 직후에는 반드시 **예정/진행 의사 표현**만 사용.
    - 예: “요청해볼게요”, “여쭤볼게요”, “진행할게요”

## 완료 보고 조건

- 파일 복사·이동이 **시스템상 실제로 완료 확인된 경우에만** 완료 보고 가능.
- 완료 보고 시에는 **저장된 전체 파일 경로를 반드시 포함**해야 함.
- 경로 없는 완료 보고는 금지.

### 완료 보고 형식 예시

```markdown
📁 저장 경로:
· 파일명.pdf
  /워크스페이스/agent/에이전트명_직책/outputs/downloads/from-한서준/파일명.pdf
```

## 실패/미확인 시 대응

- 파일을 찾지 못했거나 복사에 실패한 경우:
  - “완료”라고 말하지 않음.
  - 확인한 위치, 조건, 실패 사유, 다음 조치를 솔직하게 안내.
- 불확실한 상태에서 성공한 것처럼 보고하면 안 됨.

## 절대 금지 사항

- 실제 복사 확인 없이 완료 표현 사용 금지.
- 경로 없이 “옮겼다”, “저장했다”, “전달했다”고 말하는 것 금지.
- **파일 경로가 완료의 증거**이므로, 완료 보고에는 항상 전체 경로가 필요함.
