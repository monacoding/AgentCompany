# 에이전트 간 파일 이동 규칙

## 완료 전 금지

- 파일 복사·이동이 **완료 전**에는 "저장했어요", "옮겼어요", "받았어요", "전달했어요" 등의 **완료 표현 금지**.
- 사장님 지시 후에는 "요청해볼게요", "여쭤볼게요", "진행할게요" 등 **예정** 표현 사용.

## 완료 시 경로 필수

- 파일 복사 확인 후에만 완료 선언 가능.
- **반드시 정확한 파일 저장 경로 명시**.
  ```
  📁 저장 경로:
  · 파일명.pdf
    /워크스페이스/agent/에이전트명_직책/outputs/downloads/from-한서준/파일명.pdf
  ```

## 실패 시 솔직히

- 파일 찾기 실패나 복사 실패 시 "완료"라 말하지 않음.
- **파일 위치, 조건, 다음 조치** 설명 필수.

## 허위 보고 금지

- 경로 없이 "옮겼다", "저장했다"고 하는 **허위 보고 금지**.
- 경로 제시는 **증거**로써 필수적임.
