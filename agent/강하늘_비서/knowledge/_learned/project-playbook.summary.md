# Project 협업 플레이북 요약

## AgentCompany Project 표준 절차

### 1. 목표 설정
- 사장님 지시로부터 명확한 **한 문장 목표**를 설정, 산출물과 범위를 명확히 정의.

### 2. 계획 수립
- 프로젝트를 Phase (리서치→구현/실행→검증→PM 보고)로 나누어 관리.
- 각 태스크는 최대 5회 작업→검토 루프를 거침.

### 3. 작업 분배
- 작업 계획을 **번호 + @에이전트명: 할 일** 형식으로 문서화.
- 예시: `1. @한서준: 공식 PDF 출처 URL 조사`.

### 4. 에이전트 선별
- **Roster 내 실제 에이전트만** 사용, 외부 인력 금지.
- 역량과 역할을 기반으로 적합한 에이전트 매칭 (예: 리서치→researcher).

### 5. 승인 후 실행
- PM은 계획을 사장님께 공유하고 승인 요청.
- 승인이 떨어지면 프로젝트 채팅방 생성, 에이전트와의 협업 개시.
- 산출물은 지정된 경로로 저장되고 다음 태스크에 carry_data로 전송.

## PM 1:1 대화 출력 형식

- **목표, 계획, 작업 분배, 참여 에이전트** 형식으로 간단히 정리.

## PM 전용 — Project 오케스트레이션

- 계획 확정 전에는 프로젝트 채팅방 생성 안 함.
- **PDF 수집 업무**는 @한서준→@하정우→전문가 순서로 처리.
- **영상/콘텐츠**는 @서윤아델린 + @하정우 조합 검토.
- 승인 키워드 예시: "진행하세요", "시작하세요".

이 플레이북은 팀의 일관성을 확보하고, 효율적인 프로젝트 진행을 위해 표준 절차를 명료히 설명하는 데 중점을 둡니다. PM은 이 가이드를 따라 모든 업무 단계에서 명확하게 소통하고 인력을 효과적으로 배치하는 것이 중요합니다.
