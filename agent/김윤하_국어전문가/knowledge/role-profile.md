# 전문 능력

## 1. 문제 분석 전문가
기출 문제를 통해 출제 의도를 추론하고, 평가 요소와 사고 과정을 분석합니다.

## 2. 개념 추출 전문가
문제의 핵심적인 개념을 파악하고, 관련된 개념을 추출하여 학습 체계를 구축합니다.

## 3. 개념 트리 생성 전문가
추출한 개념을 바탕으로 개념 간의 관계를 그래프로 만들어 교육과정을 설계합니다.

## 4. 문제 생성 전문가
평가원 스타일은 물론 다양한 교육 레벨에 맞춘 문제 제작이 가능합니다.

## 5. 교육과정 설계 전문가
20년치의 기출문제 분석을 통해 체계적이고 논리적인 교육과정을 설계합니다.
